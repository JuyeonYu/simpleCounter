# TestFlight 1.1 (빌드 3) 기기 확인 체크리스트

시뮬레이터에서 확인하지 못한 항목 위주로, 확인 순서대로 정리했다.

## 0. 준비 (순서 중요)

- [ ] **App Store 1.0이 설치된 상태에서** TestFlight 빌드를 업데이트로 설치한다. 지우고 새로 설치하면 기존 데이터 이전·그랜드파더링을 확인할 수 없다.
- [ ] 1.0에서 카운터 몇 개에 숫자와 색을 넣어둔 뒤 업데이트한다.
- [ ] **Pro 구매 전에** 1~3번(무료 상태)을 먼저 확인한다.

## 1. 업데이트 후 기존 데이터

- [ ] 1.0에서 쓰던 숫자·색이 그대로 남아 있다.
- [ ] 카운터가 10개 그대로다. 페이지 점이 11개(10개 + ⊕ 페이지)다.
- [ ] 마지막 ⊕ 페이지에 자물쇠가 보이고, 누르면 Pro 화면이 뜬다. (기존 사용자 한도 10개)
- [ ] 실행할 때 Apple 계정 로그인 창이 뜨지 않는다.

## 2. 기본 기능 (무료)

- [ ] 숫자 탭: +1
- [ ] 길게 누르기(+/− 모드): 0.4초 뒤부터 계속 오르거나 내리고, 손을 떼면 멈춘다.
- [ ] 길게 누르기(리셋 모드): 한 번만 0이 된다.
- [ ] 숫자 위 빈 자리를 탭하면 레이블을 입력할 수 있다. 입력 중 숫자를 탭하면 키보드만 내려간다.
- [ ] 진동 아이콘으로 진동이 켜지고 꺼진다. 실제 진동도 확인한다.
- [ ] 색상 피커에서 아주 진한 빨강·초록(넓은 색역)을 골라도 앱이 죽지 않는다.
- [ ] 숫자 영역에서 좌우로 스와이프하면 페이지가 넘어가고, 숫자는 바뀌지 않는다.
- [ ] 앱을 완전히 종료했다 다시 켜도 마지막 값이 남아 있다.

## 3. Pro 안내 화면 (무료 상태)

- [ ] 가격 버튼에 가격이 표시된다(로딩만 계속되지 않는다).
- [ ] 홈 화면 위젯(잠긴 상태)을 탭하면 앱이 열리며 Pro 화면이 뜬다.

## 4. Pro 구매 (TestFlight는 샌드박스라 실제 결제 없음)

- [ ] 가격 버튼 → 구매 → 체크 표시 → 화면이 자동으로 닫힌다.
- [ ] ⊕ 페이지의 자물쇠가 사라지고 11번째 카운터를 추가할 수 있다.
- [ ] 진동 아이콘을 길게 누르면 휴지통이 나오고, 누르면 삭제되며 옆 페이지로 이동한다.
- [ ] 앱 삭제 → 재설치 → Pro 화면의 ↻(복원)을 누르면 Pro가 돌아온다.

## 5. 위젯 (앱을 열지 않고 카운트)

- [ ] 홈 화면 작은 위젯: 탭하면 +1, 앱은 열리지 않는다.
- [ ] 홈 화면 중간 위젯: −/+ 버튼이 각각 동작한다.
- [ ] 위젯을 길게 눌러 편집하면 카운터를 고를 수 있다. 레이블이 없으면 번호로 보인다.
- [ ] 잠금화면 원형·직사각형 위젯을 탭하면 +1. 한 줄(inline) 위젯은 표시만 된다.
- [ ] 위젯으로 센 뒤 앱을 열면 같은 숫자다.
- [ ] 앱에서 숫자·색을 바꾸면 위젯에도 반영된다.

## 6. 제어 센터 (iOS 18 이상)

- [ ] 제어 센터 편집 → 컨트롤 추가 → Count가 목록에 있다.
- [ ] 카운터를 골라 추가하면 레이블·숫자가 보이고, 탭하면 +1.
- [ ] 앱을 켜둔 채 제어 센터로 센 뒤 앱으로 돌아오면 숫자가 맞다.

## 7. 애플워치

- [ ] 워치 앱이 자동으로 설치된다. (안 되면 아이폰 Watch 앱 → 사용 가능한 앱에서 설치)
- [ ] Pro 구매 전에는 왕관 + 아이폰 아이콘이 보인다.
- [ ] Pro 구매 후 카운터가 위아래 페이지로 보이고, 색·레이블이 같다.
- [ ] 워치에서 탭하면 아이폰 숫자도 바로 오른다. (아이폰 앱이 켜져 있을 때 / 꺼져 있을 때 둘 다)
- [ ] 아이폰에서 센 값이 워치에도 반영된다.
- [ ] 워치 모드 버튼(+ → − → 리셋)이 동작한다.

## 참고

- 배경색에 맞춰 모드 버튼 색이 바뀌는 수정(`8f7a508`)은 빌드 3에 들어 있지 않다. 색 배경에서 빨간 버튼이 잘 안 보여도 정상.
- TestFlight에서는 "처음 설치한 버전" 정보가 실제와 달라서, 기존 사용자 판별은 기기에 남아 있던 데이터로만 확인된다. 1.0을 지우고 새로 설치했다면 10개 유지가 안 보이는 게 맞다.
